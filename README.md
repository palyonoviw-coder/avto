# Автожурнал — расходы и ТО машины

Веб-приложение (PWA) для телефона и ПК: журнал заправок, ТО, ремонта и прочих трат на машину,
регламент ТО с напоминаниями, отчёты и синхронизация через Google Диск.

- Сумма в записи необязательна: ТО можно отметить только датой и пробегом.
- Регламент (масло, фильтры, свечи, колодки, жидкости, шины…) заводится по шаблону, у каждого пункта
  меняются интервал в км и месяцах и время предупреждения; можно добавить свои пункты.
- Расход топлива считается между заправками «до полного бака».
- Несколько машин, документы со сроком (ОСАГО, диагностическая карта), экспорт CSV и резервная копия.
- Работает без интернета, ставится на рабочий стол («Установить приложение» в браузере).

Данные хранятся в браузере на устройстве. При входе через Google копия сохраняется в скрытой папке
приложения на вашем Google Диске — остальной Диск приложению не виден.

Основа (стили, перелистывание разделов свайпом, синхронизация) — из приложения
[Монетка](https://github.com/palyonoviw-coder/monetka).

Разработка: статический сайт без сборки. Проверки расчётов — `node --test tests/*.test.js`.

Иконки интерфейса: [Lucide](https://lucide.dev) (ISC). Перелистывание: [Swiper](https://swiperjs.com) (MIT), файлы в `vendor/`.
